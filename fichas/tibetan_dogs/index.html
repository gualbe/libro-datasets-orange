1Descripción general y estudios habituales

Cada fila es una foto de un perro, sacada de internet, con su raza, el nombre del fichero, la dirección y el tamaño de la imagen. Hay 12 fotos de cada una de seis razas: spaniel tibetano, terrier tibetano, mastín tibetano, lhasa apso, shih tzu y pequinés. El pequinés no es tibetano, pero está incluido porque se confunde a menudo con el spaniel tibetano.

Los estudios habituales son clasificar la raza con embeddings, agrupar las fotos y ver qué razas se mezclan, y predecir la raza de fotos nuevas de perros.

2

2Contexto y fuente original

Es un dataset educativo del laboratorio de Orange (2024). Según su ficha, está pensado para clasificar, agrupar y enseñar la predicción de la raza de fotos de perros cualquiera sacadas de internet. No indica de dónde son las fotos.

  • Orange Data Mining. Tibetan Dogs (datasets.biolab.si, 2024).
3

3Variable objetivo

category: lhasa_apso, mastiff, pekingese, shih_tzu, spaniel y terrier, 12 fotos cada una. Clases perfectamente equilibradas: el acierto por azar es de una entre seis (17 %).

Las razas pequeñas de pelo largo (lhasa apso, shih tzu, terrier tibetano) se parecen mucho entre sí; el mastín, grande y casi siempre oscuro, debería ser el más fácil de reconocer. La matriz de confusión lo confirma o lo desmiente.

5Particularidades técnicas al modelar

  • size, width y height pasan a atributos al abrir el CSV (en el fichero de Orange son meta). No describen al perro: ponlos como meta en File, o el modelo los mezclará con el embedding (las fotos de terrier son, de media, más altas: 219 píxeles frente a unos 195 en las demás).
  • El nombre delata la raza: image name y la ruta de image la contienen.
  • Fotos variadas: primeros planos, perros enteros, fondos de estudio y de jardín, algunos con lazos o arreglados para exposición. Es lo normal con fotos de internet y hace la tarea más realista.
  • Muy pocas fotos (12 por raza): usa validación cruzada o Leave one out.
  • Fotos pequeñas (unos 260 × 200 píxeles): Image Embedding es rápido.
6

6Flujo de trabajo en Orange

  1. File con tibetan_dogs.csv: category como target; size, width y height como meta.
  2. Image Embedding → Test and Score con Logistic Regression → Confusion Matrix: qué razas se confunden.
  3. Entrena Logistic Regression con todas las fotos.
  4. Import Images con una carpeta de fotos propias de perros → Image Embedding → Predictions.
7

7Otras consideraciones

  • Fotos de internet: el ZIP de esta carpeta las incluye para trabajar sin conexión, como el resto de imágenes de Orange; si se publican fuera del curso, conviene revisar sus derechos.
  • Es un buen ejemplo para hablar de clases parecidas y de lo que pasa cuando se le enseña al modelo un perro de una raza que no conoce: siempre responde con una de las seis.
